The signal

Expert annotations locate each beat before classification. This is a pre-segmented 600 ms window, not continuous ECG detection. N means a normal-beat annotation, not a healthy person; V means a premature ventricular contraction annotation. All other symbols are excluded.

A synthetic stress test

Shift uses edge replication, not wraparound. Noise is fixed-seed Gaussian, scaled to this window's original standard deviation. Gray is the original signal; blue is the changed signal. Each changed window is normalized again. These synthetic changes are not real recordings or validated physiological variations. The annotation belongs to the original beat.

Post-training stress checks on every eligible benchmark beat, using a fixed 0.50 threshold. All windows are re-normalized. Shift: six original samples (16.7 ms), edge-replicated. Small model.
Open notebook.

108 pair-averaged inputs → 16 seven-sample convolution filters → average pooling by 2 → 24 five-sample filters → average pooling by 3 → 32 dense ReLU units → two logits. ReLU follows both convolutions. Zero padding preserves convolution lengths. 15,994 trainable parameters.

MLII lead only. Each original 216-sample window is centered 72 samples before and 144 after the annotation at 360 Hz. Pairwise averaging produces 108 inputs. Per-window centering and standard deviation scaling use a 10⁻⁶ floor. No added baseline filtering. Paced records 102, 104, 107 and 217 are excluded. Record 114's reversed lead order is handled by name. Records 201/202 belong to the same person and stay together.

The gallery contains two N and two V examples where available per benchmark record, then the first 16 model disagreements and first 12 convolutional errors, deduplicated. It is a selected inspection set, not a prevalence sample. Every displayed prediction, derivative and perturbation is calculated locally.
